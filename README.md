# Hành Trình Học Tập

Tạo ứng dụng Learning Tracker bằng TanStack Start và TypeScript, giao diện tiếng Việt, responsive. Ứng dụng quản lý tài liệu tự học gồm tiêu đề, URL, chủ đề và trạng thái Chưa học / Đang học / Hoàn thành. Có các trang /login, /resources, /resources/new và /resources/$resourceId. Bước đầu chỉ dựng giao diện với dữ liệu mẫu. Tôi sẽ kết nối project Supabase riêng để dùng Auth và database ở bước sau. Trước khi triển khai, hãy xác nhận framework và cấu trúc routing của project. Chia công việc thành từng bước nhỏ để tôi có thể học và kiểm tra code.
